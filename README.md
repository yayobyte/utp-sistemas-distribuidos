## 📋 Sistema de Evaluación y Temas

* **Parcial 1 (20%):**
  * Introducción a los Sistemas Distribuidos
  * Arquitecturas de Sistemas Distribuidos
* **Parcial 2 (20%):**
  * Comunicación en Sistemas Distribuidos
  * Sistemas de Archivos Distribuidos y Paralelos
  * Servicio de Nombres y de Directorios
* **Parcial 3 (20%):**
  * Gestión de Procesos
  * Sincronización, Concurrencia y Transacciones
  * Fiabilidad y Seguridad
* **Actividades y Talleres (20%):**
  * Investigación o revisión de las aplicaciones del tema por cada capítulo.
* **Exposiciones (20%):**
  * Profundización sobre aplicaciones y tecnologías de sistemas distribuidos (Presentación 50%, Quiz 30%, Asistencia 20%).
